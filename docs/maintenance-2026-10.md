# 2026-10 教学计算维护

本轮优先修复会改变教学结论的计算错误，保留原有八章、43 小节的组织方式。

## 修复依据

| 示例 | 原问题 | 修正方式与验证依据 |
| --- | --- | --- |
| 卷积积分 | `same` 截取结果直接对应原时间轴，曲线与当前积分标记不一致 | 使用完整卷积，时间轴从两路起点之和开始；对照矩形与因果指数的分段解析积分 |
| 卷积性质 | 中间卷积被裁切，破坏结合律；导数遗漏因果指数起点的冲激项 | 全程保留支撑区间；使用 `x′=-αx+δ`，微分误差避开脉冲边缘不可导点及其相邻采样点 |
| 连续频谱 | 未乘采样间隔，也未补偿非零时间原点 | 对照高斯信号解析变换及平移相位；滤波逆变换同步撤销归一化和相位 |
| 三角波级数 | 原波形为偶对称三角波，重构却使用奇对称正弦级数 | 将原波形相位平移 π/2；频谱横轴显示真实的 1、3、5… 次谐波 |
| 方波功率谱 | 把三角形式正弦幅度的平方当作复指数双边功率谱 | 使用 `Cₖ=2/(jπk)`，绘制正负奇次谐波；总功率趋近 1 |
| 逆拉普拉斯 | 重极点仍按单极点指数求和，相同两极点时错误 | 使用系统冲激响应计算；验证 `1/(s+a)² ↔ t·exp(-at)u(t)`，展开式显示幂次 |
| 逆 Z 变换 | 重极点仍按单极点指数序列求和 | 使用差分方程单位样值响应；验证 `1/(1-az⁻¹)² ↔ (n+1)aⁿu[n]` |
| 左边指数 | 波形 `-exp(at)u(-t)` 与展示的 `1/(s+a)` 不对应 | 波形改为 `-exp(-at)u(-t)`，与 `Re(s)<-a` 的收敛域一致 |
| 拉普拉斯性质 | 在极点左侧的发散区域展示验证；未说明普通导数与广义导数的区别 | 横轴限制在收敛域；标明起点值与 δ 项的适用约定 |
| 反卷积 | 输出乘缩放系数，反卷积却仍使用未缩放数据 | 对实际观测输出进行反卷积，恢复结果随缩放同步变化 |
| Z 变换终值/反转 | 把末个样点当无穷远极限；反转数组却未反转索引 | `0<a<1` 的终值明确为 0；在含负索引的时间轴上展示 `x[-n]` |
| 离散零极点 | 将 z⁻¹ 系数直接作为降幂 z 多项式，漏画原点零点/极点 | 先补齐相同阶数，再转换；移动平均的两个原点极点得到保留 |
| 可观测性 | “不可观测示例”矩阵实际满秩 | 换成可控但不可观测的矩阵，验证可控秩 2、可观测秩 1 |
| 采样判定 | 临界采样频率也直接显示成功 | 临界及以下使用警告，说明任意相位信号不能保证重建；标明有限 sinc 窗截断误差 |
| 能量/功率 | 有限窗积分读数容易被误解为全时域理论量 | 指标名称标明观测窗，解释周期余弦与能量信号的理论值 |

## 工程维护

- Windows 启动脚本使用项目 `.venv`，检查 Python 版本并在失败时停止，路径包含空格时可用。
- 修正 README 中错误的 Python 3.3 版本要求；Streamlit 下限为 1.51，使用 `width="stretch"` 替代废弃的容器宽度参数。
- 页面配置放在应用入口，使计算与渲染函数可以被测试导入。
- 默认禁用使用统计并监听本地回环地址；首次依赖安装仍需要联网。
- PNG 导出优先选择本机中文字体。
- 增加标准库 unittest 测试与 GitHub Actions 平台/版本矩阵。

## 验证范围

- 数学回归以解析公式、极限和矩阵秩为依据，不以“页面没有报错”代替结果正确。
- Streamlit AppTest 遍历全部 43 个小节的默认渲染、快速示例、重置和所有下拉选项。此类交互检查用小型 PNG 替身减少渲染时间，真实 PNG 另有读回检查。
- 真实浏览器检查页面导航、快速示例/重置、PNG 下载，以及卷积和三角波页面的桌面与手机宽度布局。
- macOS 原生打包、签名及公证需要 macOS 环境验证；本轮 Windows 测试不构成 `.app` 构建成功的证据。
